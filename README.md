# Ustam — The freelance marketplace of services

Маркетплейс мастеров бытовых услуг в Ташкенте. Клиенты находят мастера по реальным ценам рынка, мастера ведут профиль, заявки, чат и финансы.

## Возможности

- **Регистрация и вход** — две роли: клиент и мастер (`/auth`).
- **Кабинет мастера** (`/pro`):
  - профиль: фото, имя, заголовок, о себе, частный мастер или сервисный центр, опыт, время выезда, телефон, Telegram;
  - услуги со своими ценами (для ориентира рядом диапазон рынка OLX), районы выезда, точка мастерской на карте;
  - переключатель «Показывать профиль клиентам». После публикации мастер появляется в поиске с меткой «На Ustam».
- **Заказы** (`/pro/orders`):
  - заявки клиентов с сайта и заказы, добавленные вручную;
  - статусы: новая → принят → в работе → выполнена (или отменена);
  - итоговая цена, запчасти, способ оплаты, отметка «оплачено».
- **Финансы** (`/pro/finance`):
  - выручка, прибыль (цена − запчасти), средний чек, долги клиентов, доля принятых заявок;
  - график за 6 месяцев, разбивка по услугам и способам оплаты;
  - экспорт в CSV для Excel.
- **Чат клиент ↔ мастер**: на странице мастера и в карточках есть кнопка «Написать мастеру». Чат открывается прямо на странице, без перехода. Вход не нужен: в демо-режиме клиент пишет как гость этого браузера и может указать имя.
  - Мастеру с Ustam сообщения приходят в кабинет, он отвечает оттуда.
  - Мастеру из OLX сообщение сохраняется, а клиент видит его телефон для быстрой связи.
  - Все диалоги собраны в `/messages`. Заявка мастеру тоже открывает чат с деталями заказа.
  - Сейчас чат локальный (localStorage). После подключения Supabase он переключится на таблицы `conversations` и `messages` из `002_marketplace.sql`.
- **Без ссылок на OLX в профилях**: телефон, Telegram, услуги, цены, районы и опыт остаются, переходов на объявления нет.
- **Карта**: точка клиента и мастеров, переключатель «Список / Карта» на странице мастеров. С ключом `VITE_YANDEX_MAPS_KEY` работают Яндекс Карты (JS API v3), без ключа — схема Ташкента.
- **Motion-дизайн**: появление блоков при прокрутке, счётчики, анимированные графики, пины на карте, анимация сообщений. Учитывается `prefers-reduced-motion`.

## Данные OLX

Источник данных о рынке — ваша база **Единственный источник данных** — ваша база `shared/data/servicesDatabase.json` (цены из объявлений OLX.uz и прайсов сервисных центров). Никаких выдуманных мастеров, рейтингов, отзывов и цен.

## Что внутри базы и как это используется

| В базе | На сайте |
|---|---|
| `categories` — 8 категорий, 53 услуги с `priceFrom–priceTo`, единицей, описанием, гарантией, источником | Каталог, страница заявки, проверка цены, страница «Источники» |
| `masters` — 19 мастеров и сервисов из объявлений OLX | База мастеров, профили, AI-подбор |
| `verifiedMasters` — 3 мастера с подтверждённым телефоном | Объединяются с объявлением по `olxListingId`. Кнопка «Позвонить» показывается только у них |
| `districts` — 13 районов Ташкента | Выбор района: AI показывает только тех, кто туда выезжает |
| `meta` — дата обновления, дисклеймер | Футер и «Источники» |

Цены мастеров берутся **только** из подтверждённого прайса или из текста объявления. Например, «чистка 150 000 сум» привязывается к услуге «Полная чистка». Если цена не указана, сайт показывает диапазон рынка и помечает его как «рынок».

## Как работает AI (без выдуманных рейтингов)

- **Понимание текста (RU/UZ/EN).** «кондиционер не холодит» распознаётся как «Заправка фреоном», «Kir yuvish mashinasi suvni chiqarmayapti» — как «Замена помпы» (`shared/matcher.js`).
- **Подбор мастера** по реальным фактам: делает ли он нужные услуги, выезжает ли в ваш район, время выезда, опыт, указанная цена относительно диапазона рынка, проверенный телефон (`src/domain/recommendation.ts`).
- **Сортировки:** лучшее по AI, дешевле, быстрее приедет, опытнее. **Фильтры:** район, частный мастер или сервисный центр, только проверенный телефон.
- **Проверка цены:** названная цена сравнивается с диапазоном OLX — «ниже рынка», «честная цена» или «выше рынка». Если в источнике указано только «от X», выше рынка считается всё, что больше 2×X.
- **Тип вызова:** на дом или в сервисный центр. Во втором случае показываются только сервисные центры.

## Запуск

```bash
npm i
npm run dev        # http://localhost:5173 — ассистент работает офлайн по базе
npm run dev:all    # + сервер AI-чата (LLM и живой поиск OLX.uz)
npm test           # тесты: база, матчер, переводы, финансы, карта, профиль мастера
```

## Обновление данных

1. Замените `shared/data/servicesDatabase.json` новой версией (в том же формате).
2. Сайт и чат подхватят её сразу.
3. Для Supabase выполните `npm run sql`. Скрипт пересоберёт `supabase/seed.sql` из того же файла.

`shared/data/servicesDatabase.js` — ваша исходная JS-версия файла, оставлена для справки. Сайт читает JSON.

## Supabase

1. В SQL Editor выполните по порядку `supabase/migrations/001_schema.sql`, `supabase/migrations/002_marketplace.sql` и `supabase/seed.sql`. Все файлы проверены на PostgreSQL.
   - `002` создаёт профили, мастеров, заказы, чаты и сообщения с RLS: каждый видит только свои заказы и переписку.
   - Включается realtime, создаётся bucket `avatars` для фото.
2. В Authentication → Providers включите Email. Для быстрого теста можно выключить «Confirm email».
3. В `.env` заполните `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.

Без Supabase сайт работает в демо-режиме: аккаунты, заказы и чат хранятся в браузере (localStorage). Синхронизация между вкладками идёт мгновенно, поэтому клиента и мастера можно проверить в двух вкладках. Каждая вкладка помнит свой вход.

## LLM для чата (по желанию)

Впишите в `.env` один ключ: `GROQ_API_KEY`, `GEMINI_API_KEY`, `OPENAI_API_KEY` или `XAI_API_KEY`.

У модели пять инструментов: `find_service`, `list_services`, `get_price_info`, `find_masters` (только реальные мастера, телефон только у проверенных) и `analyze_market` (живой поиск по OLX.uz). Системный промпт запрещает выдумывать цены, мастеров и рейтинги.

## Архитектура

```
shared/                       общий код сайта и сервера
  data/servicesDatabase.json  ← ЕДИНСТВЕННЫЙ источник данных
  normalize.js                адаптер: категории, услуги, объединение мастеров, цены из объявлений
  matcher.js                  понимание текста RU/UZ/EN, районы
  catalogI18n.js              переводы названий услуг и районов (UZ/EN)
src/domain/                   бизнес-логика: цены, AI-ранжирование, геолокация (geo.ts),
                              профиль мастера (masters.ts), финансы (analytics.ts)
src/data/                     Repository → LocalRepository (JSON) | SupabaseRepository
src/services/                 объяснения AI, чат-клиент
src/state/AuthContext.tsx     вход, роль, непрочитанные сообщения
src/ui/                       страницы и компоненты (pages/pro/* — кабинет мастера)
server/                       Express: /api/chat (SSE + tools), /api/market (OLX.uz)
scripts/build_sql.mjs         JSON → supabase/seed.sql
```

## Важно

- Описания услуг и заметки об источниках остаются на русском, как в базе. Названия услуг, категорий и районов переведены на UZ и EN.
- Мастерам с Ustam заявка уходит в кабинет и открывает чат. Мастерам из OLX заявка сохраняется у клиента, а связь идёт по телефону или через объявление.
- Демо-режим хранит пароли (хеш SHA-256) в браузере. Это только для показа: для реального запуска подключите Supabase.
